# Documentation

Every document of the repository, one line each. The [README](../README.md) is the way in: what the project is, how to run it with `make demo`, and a tour of five minutes.

## The project

- [README.md](../README.md): what DIAN e-Invoice is, what it shows, the quick start, the tour, the architecture and its limits.
- [limitations.md](limitations.md): what the project does not do, or does only in part: the DIAN, the signature, the XML, the delivery, the API, the emulated cloud, the edge, observability and the tests.
- [threat-model.md](threat-model.md): the assets, the actors, the trust boundaries, the threats with their mitigations, and the risks that remain.
- [third-party-licenses.md](third-party-licenses.md): every production dependency with its version and license, generated by `make licenses` and checked against the MIT License by `make security`.
- [SECURITY.md](../SECURITY.md): how to report a vulnerability privately, and what is in scope.
- [CONTRIBUTING.md](../CONTRIBUTING.md): the rules of the repository and the checks a change runs.
- [LICENSE](../LICENSE): the MIT License of the project.

## The cloud, as code and on an emulator

- [infrastructure.md](infrastructure.md): the production architecture on AWS, the CDK app and the serverless service, the network and the database of prod, the edge, and what serves each piece locally and in AWS.
- [observability.md](observability.md): the log line and its schema, the correlation id, the metrics, the alarms and their objectives, the notifier, and how to follow an invoice.
- [deployment.md](deployment.md): the one deployment script for every stage, what a real account needs, the first deployment, going back and tearing down; never run against an account.
